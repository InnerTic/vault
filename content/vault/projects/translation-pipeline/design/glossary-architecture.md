# Glossary Architecture

## Separation of Concerns

| File | Purpose | Generated By | Format |
|------|---------|-------------|--------|
| `canon/glossary-candidate.md` | Raw LLM extractions, per-chapter | `01-glossary.py` | Multi-field blocks `source_term:`, `suggested_english:`, `type:`, `context:`, `chapter:` |
| `canon/glossary-approved.md` | Canonical, deduplicated, human-approved | Manual curation | Simple table `\| term \| translation \|` |

## Translation Workflow

1. `01-glossary.py` scans chunks via LLM → `glossary-candidate.md` (append-only)
2. `01.5-glossary-dedup.py` deduplicates keeping first occurrence
3. Human reviews and promotes entries to `glossary-approved.md`
4. `03-translate.py` loads `glossary-approved.md` and injects into system prompt:
   ```
   Glossary (use these translations):
     一环 → First-Circle
     二环 → Second-Circle
     ...
   ```

## 环 Resolution

The character 环 (huán) appears as a rank suffix: 一环, 二环, 三环, 星环, 月环, 日环.

**Decision:** Translate as `-Circle` (First-Circle Wizard, Star-Circle, etc.)

**Rationale:** Standard in English wizard/circle-magic fiction. The alternatives — "Ring" (awkward), "Tier" (generic), "Break" (unfamiliar) — are worse fits.

**Safety net:** `05-rewrite.py` has a regex fallback:
```python
re.sub(r'\b(One|Two|...|Star|Moon|Sun|Day)-Ring\b', r'\1-Circle', content)
```

Catches any `X-Ring` the LLM produces despite the glossary instruction, without affecting legitimate "ring" uses (德鲁伊之戒 → Druid Ring, 戒指 → ring).
