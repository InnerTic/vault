# July 14, 2026

## Summary

Provisioned LXC 310 (sqlite-test) as the knowledge engine host. Set up Quartz + Caddy for static site serving. Designed and built the SQLite schema and indexer for the knowledge engine — Markdown as canonical source, SQLite as derived cache. Indexed 276 files, 631 wikilinks, 107K words.

- Knowledge indexer built and tested: frontmatter parsing, wikilink extraction, file stats
- `knowledge` CLI command: index, sync, build, publish, status
- llama-server running on port 8081 for future embedding pipeline

## Architecture Decision

Markdown is canonical. SQLite is derived. If the database is deleted, `knowledge index full` rebuilds it. This is the key design property — SQLite is a cache, not a source of truth.
